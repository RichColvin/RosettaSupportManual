Licensing & End User Customization

Overview

The Rosetta system was developed by ornamental turners for use with a rose engine. It is designed to provide the ornamental turner a way for synchronizing activities on the rose engine using stepper motors, in a manner which also assists the ornamental turner with reducing the workload for onerous tasks.

More information about the Rosetta system is available at: https://rosetta.colvintools.com/Rosetta_Overview.html.

Its software is released under the MIT/X Consortium License below. The configuration is published on GitHub.

Licensing and End User Customization

The end user of the Rosetta system may customize it for their local configuration - the intended place for HAL additions is Rosetta_Custom/Rosetta_Custom.hal. However, changes to the Rosetta files are not supported by Colvin Tools nor Brainwave Embedded.
