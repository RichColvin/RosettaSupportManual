Key Notes

halcmd

Some key commands to execute are:

halcmd show all > all.txt

halcmd show signal | grep spindle.1

halcmd -kf

More detailed information can be found in the man(ual) page for halcmd. Run man halcmd in a terminal window.

halmeter

Used to show values of signals and pins.

halscope

Used to show values of signals and pins in an oscilloscope format.

halrun

Starts a HAL session without LinuxCNC (or runs a HAL file). Not normally needed on Rosetta - use halcmd while LinuxCNC is running.

halshow

A window listing every pin, signal and parameter, with a watch list. Start it from AXIS (Machine > Show HAL Configuration) or with halshow in a terminal.

halcmd show thread

Shows each realtime thread's time. The servo-thread Max Time (in ns) should stay well under 1,000,000 (1 ms) - see Field Troubleshooting.
