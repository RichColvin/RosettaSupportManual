Key Notes

Rosetta's screens are built with GladeVCP. All the files are in /home/reuben/linuxcnc/configs/Rosetta/Rosetta_Display.

File Purpose
Rosetta_Panel_v1.ui The main side panel inside AXIS: each axis's ENA, Feed Rate and Device, the Indexing / Sync Move / Threading tabs, and the progress bar. Loaded by Rosetta.ini's [DISPLAY] GLADEVCP line; AXIS starts it as its own gladevcp process and shows it inside its window.
Rosetta_Tab_Help_v1.ui
Rosetta_Tab_TsCs_v1.ui 		The ℛ Help and ℛ License tabs. Each is started by its own EMBED_TAB_COMMAND in Rosetta.ini, so each also runs as a separate process.
Rosetta_main.py The one Python handler for all three panels above (each process runs its own copy). Because they are separate processes, they can only share information through HAL pins or RosettaSet_v1.ini.
Rosetta_PostGUI_v1.hal Loaded after the GUI starts: wires the panel's ENA buttons and indicator pins into HAL. (LinuxCNC actually loads the generated Rosetta_PostGUI_v1.local.hal copy - see Launching Rosetta.)

The Settings program is not GladeVCP

The Rosetta Settings program (Rosetta_Settings.py with Rosetta_Settings_v1.ui) is a standalone GTK program, run from the Applications menu or Rosetta_Settings.sh. It only runs while LinuxCNC is not running, and writes its settings to /home/reuben/Documents/RosettaSet_v1.ini, which the next launch reads. See Rosetta_Settings.sh.

Data types

Widget and HAL pin data types must match - see Data Types.
