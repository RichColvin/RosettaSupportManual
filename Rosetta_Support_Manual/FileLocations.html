Note: ~ is the Linux shorthand for the home folder of whoever is logged in: /home/username. On a Rosetta that is /home/rosetta, or /home/reuben on machines built before November 2026, so commands written with ~ work on both. The terminal and the file manager's address bar understand ~; a few other places don't (G-code's LOGOPEN, for one) and need the full path.

All Rosetta files are kept in the Git repository on GitHub (web site), and installed at

~/linuxcnc/configs/Rosetta

Update Rosetta (Rosetta_Update.sh) pulls the latest versions of these files from GitHub - see Updating Rosetta. The only per-machine settings file lives outside the repository, in ~/Documents.

Per-machine files (not in the repository)

File Purpose
~/Documents/RosettaSet_v1.ini This machine's settings: axis/channel assignments (channels 00 - 09), whether the expansion box is connected, scale, Max Speed, Max Acceleration, stepgen limits, PID gains and PID Max Output, backlash, jog speeds, measurement system, device names, limit jacks and switch type, E-stop button, signal tower, sounds, and the main panel's remembered values. Written by the Settings program, by Rosetta_Scale_Persist.py at LinuxCNC shutdown, and (new settings only) by an update. JSON with comment lines, despite the .ini name - don't edit it by hand. Back this up.
~/Documents/*.ini (other than RosettaSet_v1.ini) Copies made with Save All Settings As..., and Save Subset exports. Back Up to USB copies them too.
~/Documents/RosettaSet_v1.ini.bak-date-time The settings file as it was before an update added new settings.
~/.axisrc AXIS window size/position; copied from Rosetta_Setup/axisrc at install.
~/ClamAv/ Virus scan log and quarantined files.
~/.config/Rosetta/serial This machine's serial number, if one was given (Rosetta_Set_Serial_Number.sh).
~/.config/Rosetta/report_log.jsonl A copy of every version report sent by an update (see Rosetta_Update.sh).
~/.config/Rosetta/shortcuts-added Marker: the folder shortcuts have been added (Rosetta_Add_Shortcuts.sh).
~/Rosetta_Update.sh An old copy left by the installer. Not used - ignore it.
~/linuxcnc/configs/Rosetta/Rosetta.local.ini, Rosetta.local.hal, Rosetta_Display/Rosetta_PostGUI_v1.local.hal, Rosetta_Display/Rosetta_Splash.local.ngc Generated at every launch from Rosetta.ini / Rosetta.hal / Rosetta_PostGUI_v1.hal and RosettaSet_v1.ini - these are what LinuxCNC actually loads. Never edit them - they are overwritten at the next start. See Launching Rosetta.
~/linuxcnc/configs/Rosetta/gcode/ Operator's G-code programs (not in the repository). AXIS's Open dialog starts here. No file here may start with Rosetta or be named M100 - M199 - startup stops if one does (see Rosetta_Launch.sh).
~/linuxcnc/configs/Rosetta/sim.var LinuxCNC's parameter file (written while it runs).

~/linuxcnc/configs/Rosetta

File Purpose Edit?
Rosetta_Launch.sh What the desktop icon runs: generates the .local files, then starts LinuxCNC on Rosetta.local.ini. No
Rosetta_Settings.sh Starts the Rosetta Settings program. No
Rosetta_Change_Network.sh Sets up the Mesa cards' addresses (base 10.10.10.10, expansion 10.10.10.11) and the Raspberry Pi's wired connection (10.10.10.100); check shows which cards answer. See Mesa 7i92. No
Rosetta_Backup.sh What the Back Up to USB icon runs (Rosetta_Display/Rosetta_Backup.py) - see Rosetta_Backup.sh. No
Rosetta_Update.sh What the Update icon runs: pulls updates from GitHub, adds new settings, runs one-time steps, sends the version report, then runs apt update / upgrade - see Rosetta_Update.sh. No
Rosetta.ini Master LinuxCNC configuration template: step timing, home sequence, and the starting speed and acceleration limits for a new machine. This machine's own tuning is in RosettaSet_v1.ini. No
Rosetta.hal Realtime HAL template: Mesa card(s), stepgens, PID loops, E-stop latch. Its loadrt hm2_eth line is rewritten at every launch for one or both cards. No
Rosetta_Shutdown.hal Runs Rosetta_Scale_Persist.py at shutdown to save live values. No
RosettaStartupImage.gif Splash image shown while LinuxCNC starts. No
.axisrc Copy of the AXIS window settings. No

Rosetta_Custom/

File Purpose Edit?
Rosetta_Custom.hal The place for machine-specific HAL additions (loaded after Rosetta.hal). Yes*
Rosetta_Tool.tbl LinuxCNC tool table. Yes*

* These are tracked in Git, so Update Rosetta stashes local changes to them - see Updating Rosetta.

Rosetta_Display/

File Purpose
Rosetta_main.py Python handler for the side panel and the Help / License tabs (see GladeVCP).
Rosetta_Panel_v1.ui The main side panel (Indexing, Sync Move, Threading).
Rosetta_Tab_Help_v1.ui, Rosetta_Tab_TsCs_v1.ui The ℛ Help and ℛ License tabs.
Rosetta_PostGUI_v1.hal HAL wiring for the panel's ENA buttons and status (template for the .local copy).
Rosetta_Settings.py, Rosetta_Settings_v1.ui The standalone Rosetta Settings program.
rosetta_settings_io.py Shared reader/writer for RosettaSet_v1.ini.
Rosetta_Settings_Restore.py Applies saved scale / PID / velocity values to the HAL pins at startup.
Rosetta_Scale_Persist.py Saves the live values back to RosettaSet_v1.ini at shutdown.
Rosetta_Splash.ngc The empty start-up G-code file, used when X and Z aren't both assigned (otherwise the launch writes Rosetta_Splash.local.ngc).
Rosetta_Backup.py The Back Up to USB program.
Rosetta_Program_Estimate.py Works out the progress bar's percentages when a G-code program starts.
Sounds/ Rosetta_Done.wav, Rosetta_Pause.wav and Rosetta_Fault.wav - the done and pause sounds and the fault siren; Rosetta_Abort.wav - played when startup is stopped by a reserved file name.
Images/ Panel images.

Rosetta_Setup/

File Purpose
Rosetta_Generate_Local_Ini.py Builds Rosetta.local.ini and the .local.hal files at each launch (see Launching Rosetta).
Rosetta_Install_Debian_13_Trixie.sh Installer for new systems (Installation and Setup for Debian 13 Trixie); sets up the base card with Rosetta_Change_Network.sh.
Rosetta_Update_Settings.py Run by Rosetta_Update.sh: adds new settings to this machine's RosettaSet_v1.ini (see Updating Rosetta).
Rosetta_Add_Shortcuts.sh Adds the Rosetta and Gcode folder shortcuts, once. Run by the installer and by updates.
Rosetta_Set_Serial_Number.sh Asks for this machine's serial number. Run by the installer, and by updates until one is given.
Rosetta_Report_Version.py Sends the version report at each update.
REB_Install_Debian_12_Bookworm.sh The old installer for Debian 12 (Bookworm). No longer maintained - not used for new machines.
RosettaSet_v1.ini Starting settings copied to ~/Documents at install.
axisrc Copied to ~/.axisrc at install.
MesaCard/ 7i92 firmware (7i92t_Rosetta.bin, used on both the base and expansion cards), pin file, and VHDL source (PIN_Rosetta_34.vhd).
Images/ Desktop and menu icons (including the Gcode folder's Rosetta_Folder-Gcode.png), wallpaper, and logo.

Rosetta_Subroutines/

File Purpose
rosetta_thread.ngc, rosetta_thread_return.ngc G-code subroutines used by the Threading tab.

Other files in the top folder

  • LICENSE - the MIT/X Consortium License (see Licensing).
  • README.md - a short description shown on GitHub.

docs/

Design notes for developers (e.g., settings_file.md describes RosettaSet_v1.ini in detail), and Rosetta_Tracker.md - the list of open, untested and recently settled items.
