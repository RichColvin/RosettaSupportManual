This page is for building the boxes with the Rosetta circuit board. The board connects the Mesa 7i92TH card to the DM542T drivers, the limit jacks, the E-stop button and the signal tower, and has the signal tower's relays built in.

This page is an outline. It will be completed when the PCB design is final.

Before starting:

  • Get the parts marked Both and Rosetta PCB on Hardware Parts.
  • Do the common build steps (DM542T switches, Mesa jumpers, network and power).

Network Connections

One board, two boxes

Both boxes use the same PCB. The expansion box's board has fewer parts fitted:

Part of the PCB Base box Expansion box
Driver connections 6 (channels 00 - 05) 4 (channels 06 - 09)
Limit jack connections 3 (Limit Jacks 1 - 3) 3 (Limit Jacks 4 - 6)
E-stop button connection Fitted Not fitted
Signal tower relays Fitted Not fitted
Mesa card headers used P1 and P2 P2 only
Other parts To be completed To be completed

Which pin does what

The PCB carries each signal to the same Mesa card pin as a breakout-board build, so the software doesn't need to know which build a machine is. The full map is on Mesa 7i92TH Pin Mapping.
