Connector P1

Connector P1 is not used for this design.

Notes

  1. Limit switches
    • GX-12/2 plug
    • Normally Closed (NC) switches are recommended.
    • Limit Jacks 1 - 3 are on the base card; Limit Jacks 4 - 6 are on the expansion card and work only while Expansion Box - Connected is ticked.
    • When set to Normally Open (NO) in the Rosetta Settings program, LinuxCNC reads the card's inverted input for that pin (.in_not instead of .in), so no NOT function is needed.
    • See also,
      • Limit Switch Cabling
  2. E-Stop Button
    • GX-16/2 plug
    • E-stop button must be a Normally Closed (NC) switch
    • See also,
      • E-stop Button Cabling
  3. Breakout Power
    • W3 switches the 5V breakout power on connector P1, and W4 on connector P2. For more information, see 7I92 Ethernet Anything I/O Manual, pg. 2
  4. Signal Tower
    • GX-12/4 plug
    • Active low from 7i92
    • See also,
      • Signal Tower
      • Signal Tower Cabling
      • Signal Tower Relays
  5. Signal Tower Red Light
    • On after a following error, a limit trip, or a Mesa card losing contact; stays on until the machine is next switched on (F2).
  6. Signal Tower Green Light
    • On while a program or MDI command runs, and while a spindle is running or indexing.
  7. Signal Tower Buzzer
    • The 3-second fault siren (when red comes on), and the done / pause beeps - each can be set to the tower, the speaker, both, or off in the Settings program.
