Face Plates


USB HDMI Face Plate


Base Box Face Plate


Expansion Box Face Plate

The face plates for the base box and the expansion box are both in this file. They are on separate plates within the file.

  • REB_Plates_v1.3mf

Printing Notes

  1. These should be printed with the text down. That gives the best, flattest surface for the plate’s surface which is seen.

Power Supply Mount


Power Supply Mount

This is used to hold the 24V -> USB power supply which is used to power the Raspberry Pi and the Mesa 7i92TH.

  • REB_PowerSupplyMount.3mf

Printing Notes

  1. This should be printed as shown (with the bottom down).
  2. Supports are not needed.

Signal Tower Relays Mount


Signal Tower Relays Mount

This is used to hold the 3 relays used for control of the signal tower.

  • REB_Relay_Mount.3mf

A cable tie placed between the top relay and the next one down helps hold all 3 snugly in place.

Printing Notes

  1. This should be printed as shown (with the bottom down).
  2. Supports are not needed.

Compatibility Notes

  1. They are provided as a 3mf file which is formatted for printing on a Bambu Lab printer with multiple filament support. This enables the text to be embedded into the front as a different color.
  2. These were tested on a Bambu Labs P1S with an AMS.
