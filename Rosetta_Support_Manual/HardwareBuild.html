Hardware Build for the Rosetta

Building a Rosetta: 1. Parts · 2. Common build steps · 3a. With the Rosetta PCB · 3b. Without the PCB · 4. Software

A Rosetta is a base box and, optionally, an expansion box. There are two ways to build the boxes:

  • With the Rosetta PCB - the Rosetta circuit board connects everything, and has the signal tower's relays built in.
  • Without the PCB - the Mesa card's headers are brought out to screw-terminal breakout boards, and everything is wired to those.

Both give the same machine, and run the same software.
