Diagnostics

Errors in LinuxCNC

One of the best tools to use when trying to diagnose errors in LinuxCNC, especially for Glade, is to run the system in diagnostic mode by adding the “-d” option.

Do not run Rosetta.ini directly. Rosetta is always started through the launch script, which first generates Rosetta.local.ini and the .local.hal files from this machine's settings (see Launching Rosetta). Running Rosetta.ini directly would start LinuxCNC with the default axis layout, only the base box's card, and without the operator's limit switches, E-stop button, signal tower, lost-card E-stop, jog speeds, or units.

To run in diagnostic mode, open a command prompt and enter this:

cd /home/reuben/linuxcnc/configs/Rosetta
python3 Rosetta_Setup/Rosetta_Generate_Local_Ini.py
linuxcnc -d Rosetta.local.ini

Errors encountered will be displayed in the command prompt area.

LinuxCNC can also be run in verbose mode by adding the “-v” option.
