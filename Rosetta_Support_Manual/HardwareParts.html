Hardware Parts for the Rosetta

Building a Rosetta: 1. Parts · 2. Common build steps · 3a. With the Rosetta PCB · 3b. Without the PCB · 4. Software

This is the one parts list for both ways of building a Rosetta. The Applies to column says which build each part is for:

Both Needed for either build.
Rosetta PCB Only when building with the Rosetta circuit board - see Hardware Build With Rosetta PCB.
Without PCB Only when building without it, using breakout boards - see Hardware Build Without PCB.

Without the PCB, the case and power parts (1000 - 1199 and 2000 - 2199) are the builder's own choice, so they are listed for the Rosetta PCB build only.

The expansion box (part numbers 2000 - 2499) is optional. Part numbers stay the same whichever build is chosen.
